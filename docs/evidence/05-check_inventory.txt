# check_inventory (onlyLow)

## Request (JSON-RPC over Streamable HTTP, POST /mcp)
```json
{
  "method": "tools/call",
  "params": {
    "name": "check_inventory",
    "arguments": {
      "onlyLow": true
    }
  }
}
```
