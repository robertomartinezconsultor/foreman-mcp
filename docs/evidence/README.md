# Evidence transcripts

Generated by `node scripts/evidence.mjs` (plus one manual real-store run).
Every file is a real request/response capture against the built server,
not a mockup.

| File | What it proves |
|---|---|
| `00-initialize-and-tools-list.txt` | MCP 2025-11-25 negotiation and the full 11-tool surface |
| `01-get_day_briefing.txt` | Composite owner briefing from live state |
| `02-list_jobs.txt` | Tomorrow's schedule with crews (and the unassigned job) |
| `03-get_job.txt` | Job detail with its field-update thread |
| `04-get_unanswered_leads.txt` | Leads past the response SLA, longest wait first |
| `05-check_inventory.txt` | Low-stock detection (thinset, tile) |
| `06-run_morning_dispatch.txt` | The agentic flow: 6 gaps found, 3 dispatches queued, shopping draft created |
| `07-assign_crew.txt` | Action with effect: the gap from file 06 gets fixed |
| `08-log_field_update.txt` | Field data entering the business memory |
| `09-record_lead_reply.txt` | A 52h-stale lead closed with a reply on its thread |
| `10-queue_dispatch.txt` | Manual dispatch into the persistent outbox |
| `11-create_shopping_list.txt` | Approval-gated shopping draft (nothing is purchased) |
| `12-persistence-after-restart.txt` | Boot 2 on the same store: every boot-1 mutation still there |
| `13-real-store-persistence.txt` | Same proof against the shipped default `data/store.json` |

Regenerate any time with `npm run build && node scripts/evidence.mjs`.
The automated gate is `node scripts/verify.mjs` (44 assertions, two boots).
